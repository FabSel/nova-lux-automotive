Un faro original de Volkswagen Derby transformado mediante una intervención completa de iluminación y diseño.


El proyecto integra un proyector de lupa, iluminación DRL y una guía de acrílico diseñada específicamente para generar una firma luminosa propia.


La intención no fue simplemente modificar el faro, sino construir una identidad visual nueva conservando la esencia del vehículo original.
